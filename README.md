# ✨ JHora AI 提问助手

一个帮助用户向 AI 精准提问的吠陀占星工具。解决“数据有了，不知道该怎么问”的断层问题。

在线地址: [https://jhora-prompt.pages.dev](https://jhora-prompt.pages.dev)  
源码: [https://github.com/Zzx-LiU6/jhora-prompt](https://github.com/Zzx-LiU6/jhora-prompt)

## 🧠 为什么做这个项目

这个项目的起点并不是“我要做一个 Prompt Generator”。

在和 AI 讨论塔罗、六爻、大六壬、西占与印占的过程中，我逐渐产生了一个问题：

> 如果不同体系本身有不同的分析逻辑，那么当我让 AI 分析一个星盘时，我究竟应该告诉它关注什么？

进一步思考后，我发现：

**用户可能并不是“不知道怎么写 Prompt”，而是根本不知道一个复杂的分析任务应该从哪些维度开始。**

于是我开始尝试把自己的分析过程拆解成一条清晰的链路：

> 分析场景 → 所需数据 → 分析维度 → AI 指令

这个工具就是这条思考链路的产品化落地。

## ⚖️ 重要设计取舍

- **场景驱动的问题拆解，而非开放式 Prompt 生成**：不提供“自由输入想分析什么”的空白框，而是引导用户先选主题 → 再选场景 → 最后勾选具体问题。这种结构化的交互方式虽然限制了“自由发挥”的空间，但大大降低了初次使用者的认知门槛。

- **双模式切换：主题 vs 分盘**：
  - **按主题提问**（生活场景驱动）：适合不熟悉占星术语的初学者，从“感情”“事业”“财运”等生活话题切入。
  - **按分盘解读**（占星体系驱动）：适合有一定基础的进阶用户，从 D1/D9/D10 等分盘的专业分析框架切入。
  两种模式互补覆盖了不同深度、不同背景的用户需求。

- **数据输入与 Prompt 生成解耦**：用户可以先粘贴星盘数据，再生成 Prompt，数据会自动填入【星盘数据】占位符。但如果用户没有数据，也可以先生成 Prompt 框架再去清洗数据，**两个工具的配合是松耦合的，不强制顺序**。

- **星体知识库 + 场景配置的架构**：将 30+ 场景的配置（每个场景需要哪些数据、哪些星体、哪些问题维度）集中管理在 `config/` 目录下。这种配置驱动的设计使得新增或修改一个场景无需改动核心代码逻辑，降低了维护成本。

## 🚧 已知局限与未来计划

- **分析框架的权威性**：目前的分析框架主要基于个人使用经验、公开资料和 AI 辅助整理，并不代表某一占星流派的唯一分析方式。后续计划通过更多真实用户反馈来持续迭代和验证。

- **术语解释的覆盖范围**：目前内置的术语自动解释主要针对常见占星术语，部分更小众的概念可能尚未覆盖。未来可考虑建立一个完整的术语库。

- **数据输入的校验能力**：当前对用户粘贴的星盘数据仅做简单的占位符替换，未做深度校验。后续可考虑与清洗工具做更深度的联动，例如自动识别用户复制的是 D1 还是 D9 数据。

## ✨ 核心功能

### 📋 按主题提问（原有）
- **六大主题覆盖**：感情婚姻、事业发展、财富运势、身心健康、学业教育、大运流年
- **场景化引导**：每个主题下细分具体场景（如“单身脱单”“已婚趋势”“求职跳槽”）
- **问题清单勾选**：用户只需勾选自己关心的问题，系统自动拼装专属 Prompt
- **三层数据深度**：根据场景自动匹配需要的数据（D1/D9/D10/D24/大运/Gochara 等）
- **一键复制 Prompt**：生成后可直接粘贴到 ChatGPT、DeepSeek、Claude 等 AI 平台
- **术语自动解释**：每个 Prompt 涉及的专业术语自动生成解释，降低学习门槛

### 📊 按分盘解读（新增）
- **10 个核心分盘覆盖**：D1 本命盘、D2 财富盘、D3 手足/沟通盘、D4 家庭盘、D6 健康盘、D7 子女/创造盘、D9 婚姻盘、D10 事业盘、D12 父母盘、D24 教育盘
- **结构化分析框架**：每个分盘预设专业的分析维度（如 D9 包含上升、7宫、金星、D1-D9交叉验证、Yoga等）
- **Dasha 大运时间线推演**：每个分盘分析均附带大运时间线，将静态格局落实到动态人生节奏
- **灵活数据输入**：支持粘贴星盘数据后自动填入 Prompt 占位符
- **一键复制**：生成后可直接粘贴到任意 AI 平台

## 🚀 本地运行

这是一个纯静态 HTML 项目，无需安装任何依赖。克隆后直接用浏览器打开 `index.html` 即可。

```bash
git clone https://github.com/Zzx-LiU6/jhora-prompt.git
cd jhora-prompt
# 直接用浏览器打开 index.html
```

## 📖 使用流程

### 按主题提问
1. 选择主题（感情/事业/财运/健康/学业/大运）
2. 选择具体场景（如“单身脱单”）
3. 勾选你关心的问题（可多选）
4. 点击「生成专属提问话术」
5. 复制 Prompt，粘贴到 AI 平台，替换【星盘数据】部分

### 按分盘解读
1. 切换到「按分盘解读」Tab
2. 在数据输入框中粘贴清洗后的星盘数据（可选）
3. 点击你想要深入分析的分盘卡片（如 D9 婚姻盘）
4. 系统自动生成包含专业分析框架的 Prompt
5. 如已粘贴数据，【星盘数据】区域自动填入
6. 一键复制 Prompt，粘贴到 AI 平台

## 🔗 与 JHora 清洗工具的关系

建议配合使用 [JHora 星盘清洗工具](https://jhora-clean.pages.dev)：

1. 用清洗工具将 JHora 原始输出整理为标准化星盘数据
2. 用提问助手生成专属提问话术
3. 将清洗好的数据粘贴到 Prompt 中，发给 AI
